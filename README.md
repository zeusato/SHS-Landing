# SHS Landing (No-Scroll) — Glass UI

A Vite + React + TypeScript + Tailwind project pre-wired with framer-motion and lucide-react.

## Quick start

1. Install Node.js 18+
2. Open terminal in this folder and run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the URL shown (default http://localhost:5173).

## Build
```bash
npm run build
npm run preview
```

The main component lives in `src/SHSNoScrollLanding.tsx` and is rendered by `src/App.tsx`.
